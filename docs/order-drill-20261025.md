# 語順整序ドリル：選択操作と難易度

対象：FY26A 大問3を起点とする語順整序ドリル。原本PDF4ページ目（印刷ページ2）を視認して照合。

## 不具合

類題の語句は span 要素として表示され、タップできなかった。過去問の並べ替えでは既に共通 answer-widgets を使用していたが、ドリルには接続されていなかった。共通ウィジェットをドリルにも接続し、同じ語が複数ある場合もインデックス単位で選択する。選択時に画面全体を再描画せず、スクロールと入力フォーカスを保持する。ドリルの語句ボタンは44px以上のタップ領域を確保する。

## 難易度判断と教材

原本の大問3は「和文を参考に並べ替え、不足語1語を補う」。元の6類題は全て level 1 で、不足語なし。一部は句のまとまりが大きく、本番到達の判定には不十分だった。また各 target に1題しかなく、現在の厳密な出題対象選択では5つの独立familyという開始条件を満たさなかった。古い広域選択で保存されたドリルでは、過去完了の誤答に対し過去分詞修飾の類題が紐付く例もあった。

6項目（過去完了・関係節と前置詞・未来進行形・interested in・過去分詞修飾・期間の現在完了）を各5題、計30題へ整備した。残りの36類題、過去問の問題・正答、保留用FY26Bは変更しない。

- 基礎1題：語順を確認する。修飾の類題では語句を細分化。
- 本番形式2題：同じ文法項目の別文で、不足語を補う。過去分詞修飾では by だけを問うのではなく、made / sung / taken / painted 自体を補う。
- 翌日の未出題2題：本番形式のまま別文で定着を確認。

level 3 は学校公式の難易度やCEFRを意味せず、未出題の定着確認用。中学3年生の入試対策として、原本の構文と操作条件に合わせた設計判断であり、実測された合格水準や全科目・全問題の難易度保証ではない。

## 保存と復旧

並べ替え状態は語句のインデックスと補充語を保存。未完成では提出できない。更新前の未回答類題の語句が変わった場合は、旧下書きを recoveredDrills に退避し、同じ弱点の基礎から再開する（旧形式の確認問題で克服判定がつかないようにする）。元の弱点と異なる文法項目の未回答ドリルも退避し、同じ弱点の基礎から再開する。既存の採点履歴を保持する。

## 検証

- tests/order-drill.test.mjs：各targetの5family、段階構成、未出題確認の予約、未完成・誤答。
- tests/order-drill-browser-checks.mjs：390/1280pxで実タップ・クリック、重複語、戻す、やり直す、再読込、3問＋翌日2問、補充語の誤答、古い誤対応の復旧。
- 全66類題のトークン構成・解答・別解の整合を material-integrity と実ブラウザで確認。
- 手元のブラウザ取得はダウンロードエラー。ローカルのブラウザ成功は主張しない。正確な候補コミットのGitHub verify成功後にmainへ反映し、mainのverify成功後にPagesが公開する。公開後もproductionジョブで同じ実操作テストを行い、外部の進捗同期通信は遮断した独立ブラウザで確認する。

release.json の以前のcandidate証跡は過去のリリースに関するもの。更新したコンテンツハッシュは今回の検証対象を固定するもので、過去の成功証跡を今回の成功として流用しない。
