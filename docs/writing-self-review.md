# FY26A writing practice

FY26A Q8 is available as local writing practice from the paper screen and Guide.
The preserved source prompt is displayed verbatim. The app provides an approximate
English word count and six self-review questions covering the requested ability,
events, feelings, problems/adventures, narrative order and language revision.

These checks are app-authored, not an official marking rubric. No points, automatic
correctness, mastery, or exam completion are generated. AI writing stays disabled.
Editing the text clears earlier checks so a revised answer must be reviewed again.

The draft and checks autosave inside the existing school-local state and are included
in its export/replace import. Merge keeps the current local draft when one exists;
the selected incoming backup remains available to the user. Existing exam, drill,
weakness, Cloud credential and summary contracts are unchanged. Writing text is not
included in any Cloud payload. Reset clears the draft with the other learning state.

FY25 picture tasks remain unavailable until the original images are prepared.
FY26B remains excluded from training. The existing writing runtime policy refers
to exam marking; its selfReviewPractice entry describes this separate feature.

Validation covers word counting, safe rendering, source boundaries, two browser
widths, reload, checklist invalidation, export/reset/replace and merge preservation.
